# Capability Map — the full platform vision (podcast → operating system)

The Pace Morby session isn't two features — it's a blueprint for an **end-to-end real
estate operating system**. This map turns every concept in it into a module, organized by
the **deal lifecycle**, with status. The platform today is deep on ANALYZE + FINANCE; the
rest is the runway.

Status key: ✅ built · 🟡 spec'd (007/008/009/010) · 🔵 idea (next specs)

---

## The lifecycle (the spine)

### 1. SOURCE — find motivated sellers
- ✅ Owner / absentee / tenure / equity signals (002)
- 🟡 Motivation typing + "bunny" inference + outreach (008): tired-landlord, probate,
  pre-foreclosure, tax-delinquent, expired/stale
- 🔵 **Lead-stacking engine** — combine multiple motivation signals (absentee + tax-delinquent
  + high-equity); research says stacked lists convert far better
- 🔵 **Acquisition-channel router (DTS / DTA / DTR)** — per lead, pick channel + who to contact
  (seller vs listing agent vs referral source like probate attorneys)
- 🔵 **Vendor lead adapters** — AllTheLeads (probate), DealSauce/PropStream (foreclosure),
  Vulcan7/Privy (expired/MLS) behind one interface

### 2. ANALYZE — what's the best use of this property
- ✅ Underwrite + score, by-room vs whole-house, off-prime judgment (003)
- 🟡 **Exit-strategy optimizer** (007): LTR / by-room / MTR / STR / Section 8 / HUDVASH
- 🟡 **Highest-and-best-use + development engine** (009): evaluate across ALL FOUR WAYS
  (wholesale / fix-flip / develop-build / hold) and flag **ADU / add-units / tear-down-rebuild**
  unlocked by the upzoning — the land-vs-improvement value play
- 🔵 **Multi-asset underwriting** — extend beyond SFR to small multifamily, RV/mobile-home
  parks, self-storage (Pace's favorites carry different pro-formas)
- 🔵 **Rehab/repair cost estimator** — for the fix-flip / develop paths

### 3. FINANCE — how to structure the deal
- ✅ Creative-finance engine: cash / seller-finance / sub2 / hybrid, NEED vs GREED,
  cap-gains seller-win, legal guardrails (004)
- 🟡 **Equity & distress engine** (010): true equity (value − loan − cost-to-sell),
  negative-equity / "would write a check" → sub2 targets, distress scoring + map layer
- 🔵 **Full 26-strategy creative library** — lease options, Morby method, wraps,
  contract-for-deed, dating/innovation agreements (engine does ~5 today)
- 🔵 **Seller net-proceeds comparator** — show the seller their after-tax outcome cash vs
  terms (the persuasion tool, generalized)
- 🔵 **Gator / private-lending module** — Nate has capital: model deploying it as a lender
  (today-money), and source the EMD/gap funding for his own deals

### 4. ACQUIRE — win and close it
- 🔵 **AI negotiation & script coach ("deal detective")** — per-lead talk tracks from the
  bunny, objection handling, roleplay (Pace's "daily dial" as software)
- 🔵 **Offer / LOI generator** — per financing structure (already a 004 future hook)
- 🔵 **Transaction pipeline / TC layer** — checklist per deal (EMD, title, inspection,
  closing); the "service" roles as workflow

### 5. OPERATE — run the asset
- 🔵 **Exit-strategy execution playbooks** — once a strategy is chosen (e.g., by-room
  student), the lease structure, guarantor, turnover calendar
- 🔵 **Property-management hooks** — turnover/vacancy tracking feeding the next score

### 6. COMPOUND — grow the portfolio
- ✅ Scout-diff "what changed" + regulatory radar (006)
- 🔵 **Portfolio strategy advisor** — today/tomorrow/forever-money tagging; "given what you
  own, what's the best next buy" (diversify markets, manage concentration)
- 🔵 **LEARN loop** — capture `deal.outcome`, retune thesis weights to Nate's realized results
- 🔵 **Disposition / network module** — route excess deal flow to buyers; source from
  wholesaler feeds

## Cross-cutting intelligence (sits over the whole spine)
- 🔵 **Path-of-progress / land-banking analyzer** — building permits (layer 21) + master-plan
  + enrollment growth → spot appreciation corridors before they move (trust-capital, long horizon)
- 🔵 **Marketing-ROI / spend optimizer** — cost-per-deal by channel (mail $/piece, skip-trace
  12¢, PPC) so capital goes where it converts (Pace's "$5k → 20 calls → 3 deals" math)
- 🔵 **Funnel / KPI dashboard** — leads → contacts → appointments → contracts → closes, per channel
- 🔵 **The "you-investor" profiler** — extend the thesis: personality, risk, time, capital →
  which plays fit (the "stop asking the new-investor question" framing)
- ✅ **Judgment / knowledge layer** — every recommendation cites the KB rule (the moat)
- 🔵 **Counterfactual / scenario engine** — "if rates drop 1%", "if the upzoning reverts"

---

## How it composes (the genome)
Each module reads/writes the **Deal Genome** (the per-property feature view). SOURCE adds
motivation; ANALYZE adds best-use + exit strategy; FINANCE adds structure + equity/distress;
ACQUIRE adds the script/offer; COMPOUND adds outcome → feeds LEARN. The same property flows
through all six stages, getting richer — that's the difference between a tool and a system.

## Suggested build order (beyond 007/008)
1. **009 Highest-and-best-use + development** — unique, ties to the upzoning, big upside.
2. **010 Equity & distress engine** — powers sub2 sourcing + the distress map.
3. **AI negotiation/script coach** — the differentiating ACQUIRE piece (next spec).
4. **Lead-stacking + vendor adapters** — scales SOURCE.
5. **Path-of-progress** + **portfolio advisor** + **LEARN loop** — the COMPOUND layer.

Everything here traces to a specific moment in the source material; nothing is invented for
its own sake. Build the spine deep on Charlottesville, then the same modules light up Miami
and every next market.
