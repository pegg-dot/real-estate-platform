# Concept: Glossary (real estate + creative finance terms)

Plain-English decoder. Add terms as new sources introduce them.

| Term | Meaning |
|---|---|
| **Wholesale** | Put a property under contract, then sell/assign the contract to a buyer for a fee — without ever owning it. |
| **Bird dog** | Someone who finds deals/leads for an investor for a fee; entry-level wholesale role. |
| **Orbit** | Joining an established investor's team to learn by doing ("you're the planet orbiting their sun"). |
| **DTS / DTA / DTR** | Direct to Seller / Direct to Agent / Direct to Referral — the three ways to source a deal. |
| **On-market / Off-market** | On-market = listed with an agent (don't call the seller). Off-market = not listed; you reach the owner directly. |
| **Exit strategy** | How you make money on a property once owned (Section 8, Airbnb, flip, etc.) — NOT how you found/financed it. |
| **Buy & Hold** | Own the asset for income (rentals of all kinds). |
| **LTR / STR / MTR** | Long-term / Short-term (Airbnb) / Mid-term rental. |
| **Section 8** | Government pays part of a tenant's rent. |
| **HUDVASH** | Section 8 for veterans. |
| **Co-living** | Renting by the room. |
| **Land banking** | Buying land in the path of growth and holding years for appreciation. |
| **Fix & flip** | Buy, renovate, resell. |
| **BRRRR** | Buy, Rehab, Rent, Refinance, Repeat (not named in source 1 but standard; placeholder). |
| **Subject-To (sub2)** | Buying a property by taking over the seller's existing mortgage payments; loan stays in seller's name. |
| **Seller finance** | The seller acts as the bank — you pay them over time instead of getting a bank loan. |
| **Morby Method** | One of Pace Morby's creative-finance exit structures (detail TBD from a future source). |
| **Hybrid** | Combining sub2 + seller-carry on one deal. |
| **Gator** | A private lender who funds the small short-term gaps in creative deals (EMD, down payment, etc.); also a Sub2 role. |
| **EMD** | Earnest Money Deposit — good-faith money put down to secure a contract. |
| **Hard money / Private money** | Short-term, asset-based loans (institutional vs. individual) used for flips/acquisitions. |
| **TC (Transaction Coordinator)** | Service provider who handles a deal's paperwork. |
| **Title company / Closing attorney** | Neutral clearinghouse that verifies parties and records the new owner with the county. |
| **Skip tracing** | Looking up a property owner's phone/contact info (~12¢/number). |
| **Driving for dollars** | Driving neighborhoods to spot distressed/ugly houses as leads. |
| **PPC / PPL** | Pay-Per-Click / Pay-Per-Lead (a resold PPC lead). |
| **Inbound / Outbound** | Seller contacts you (high intent) / you contact the seller (lower intent). |
| **Bunnies** | The emotional, underlying reason a seller needs to sell. Find them, solve them. |
| **Tired landlord** | Long-time small landlord, self-managing, burned out — prime motivated seller. |
| **Concessions / Credits** | Money the seller gives back to the buyer (for repairs or to the buyer's lender) at closing. |
| **Due-on-sale clause** | Mortgage provision letting a lender demand full repayment if the property transfers — the key Subject-To risk. |
| **Capital gains** | Tax on the profit from selling an appreciated asset; deferrable via seller financing. |
